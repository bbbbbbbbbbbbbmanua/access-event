# Анализ предметной области: AccessEvent

## 1. Описание предметной области
AccessEvent — платформа для организации мероприятий
с акцентом на доступность для людей с нарушениями слуха.

## 2. Сущности и атрибуты

| Сущность | Атрибуты | Описание |
|----------|----------|----------|
| Event | id, title, date, location, description, is_inclusive | Мероприятие |
| Participant | id, name, email, phone, hearing_status | Участник |
| Organizer | id, name, contact, rating | Организатор |
| Registration | id, event_id, participant_id, status, created_at | Регистрация |
| Notification | id, event_id, type, message, color | Уведомление |
| Review | id, event_id, participant_id, rating, text | Отзыв |
| Category | id, name, description | Категория события |

## 3. Бизнес-процессы

### 3.1. Создание мероприятия
Организатор создаёт мероприятие, указывая дату, место,
описание. Может отметить как инклюзивное.

### 3.2. Регистрация на мероприятие
Участник находит мероприятие, регистрируется.
Статус: ожидание -> одобрено/отклонено.

### 3.3. Визуальное уведомление
За 30 минут до начала система показывает цветной баннер
(зелёный — началось, жёлтый — скоро, красный — отмена).

### 3.4. Текстовый чат
Участник пишет в чат на странице мероприятия.
Организатор видит и отвечает.

### 3.5. Отзыв на мероприятие
После завершения участник может оставить отзыв
(оценка + текст).

## 4. Роли пользователей
- **Организатор** — создаёт и управляет мероприятиями
- **Участник** — регистрируется и посещает мероприятия
- **Администратор** — контролирует платформу
- **Гость** — просматривает мероприятия без регистрации
