# access-event это веб-платформа для организации мероприятий с акцентом на доступность для людей с нарушениями слуха. Система позволяет организаторам создавать мероприятия, а участникам — регистрироваться на них, получать визуальные уведомления и общаться через текстовый чат.
В течение 6 дней практики (36 часов) вы пройдёте полный цикл разработки: от анализа до защиты проекта. Сегодня — День 1: предпроектный анализ и техническое задание.
