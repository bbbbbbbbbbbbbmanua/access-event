# access-event

Веб-платформа для организации мероприятий с акцентом на доступность
для людей с нарушениями слуха.

## О проекте

AccessEvent — это веб-платформа для организации мероприятий с акцентом
на доступность для людей с нарушениями слуха. Система позволяет
организаторам создавать мероприятия, а участникам — регистрироваться
на них, получать визуальные уведомления и общаться через текстовый чат.

Проект разработан в рамках учебной практики по специальности
09.02.07 «Информационные системы и программирование»,
ПМ.05 «Проектирование и разработка информационных систем».

## Стек технологий

- **Backend:** Python 3.10+, Flask 2.3+
- **База данных:** PostgreSQL 14+
- **Шаблоны:** Jinja2
- **CI/CD:** GitHub Actions + GHCR
- **Тесты:** pytest

## Структура проекта

- `docs/` — предпроектная документация
- `.github/workflows/` — CI/CD проверки
- `src/` — исходный код
- `tests/` — тесты
